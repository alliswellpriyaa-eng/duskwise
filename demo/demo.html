Duskwise ships as one CSS file. Add the optional engine and the page follows sunrise and sunset at your visitor's location.

90 primitive colors and 28 theme colors in OKLCH, 22 semantic color roles per mood, and optional component tokens such as --dw-btn-bg.

About 6 KB minified. It writes one attribute and one CSS variable to the page and never touches your components.

Why the screen should follow the sky

Your eyes adapt to the room around you. At noon a bright white page feels normal; at night the same page glows like a lamp. Comfort lowers blue light and brightness after sunset, inside your app only, so the reading experience matches the room you're sitting in.

Text contrast never drops below 4.5:1, whatever the mood.

The line length stays near 68 characters, headings balance their lines, and light text gets slightly lighter weight at night, because light-on-dark type looks heavier than it is.

Install

One stylesheet, one optional script

CSS only

npm install duskwise import "duskwise/duskwise.css";

With the ambient engine

import { createAmbientTheme } from "duskwise"; const theme = createAmbientTheme({ mode: "auto", nightWarmth: 0.12, });
